Configuration¶

Every setting is a field of wiki_api.config.Settings and a WIKI_API_ prefixed environment variable (Example: http_port is WIKI_API_HTTP_PORT).

Read from four places, first Settings arguments, then local environment .env finally config file deploy.json.

deploy.json sits beside the keys, or wherever WIKI_API_CONFIG_FILE names. Copy deploy.example.json for a complete one. Each install puts both somewhere already:
